## Same-profile meeting gate

Run this flow independently for every supported endpoint profile. The two users
keep their own credentials and MCP configuration on their own machines.

1. The organizer creates a timed meeting for the other user.
2. The attendee receives the request and accepts it; the organizer receives the
   response and both users verify the Calendar item.
3. The organizer changes the time and attendee role; the attendee receives the
   update and responds tentatively, then declines.
4. The organizer cancels the meeting; the attendee receives the cancellation
   and both users verify cleanup.

Record only redacted operation statuses, elapsed delivery times, and cleanup
results. Cross-profile delivery is informative but does not affect acceptance.
